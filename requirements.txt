# --- STT local (faster-whisper na GPU) ---
# Puxa sozinho huggingface_hub, tokenizers, av e onnxruntime. Nenhum dos quatro
# esta listado aqui, mas o onnxruntime nao e opcional na pratica: o config tem
# vad_filter=true e o VAD do faster-whisper (Silero) roda nele.
faster-whisper==1.2.1
ctranslate2==4.8.2

# --- CUDA userspace, via wheels ---
# O ctranslate2.dll carrega cublas64_12.dll e cudnn*.dll DINAMICAMENTE: essas DLLs
# nao estao na import table do PE. Sem elas o modelo ate carrega em device="cuda",
# e so o transcribe() estoura com "Library cublas64_12.dll is not found".
# Por isso wispr/stt.py chama os.add_dll_directory() em cada nvidia/*/bin ANTES de
# importar faster_whisper (e usa nvidia.__path__, porque nvidia e namespace package
# e nvidia.__file__ e None). Ver docs/ARCHITECTURE.md secao 2.
# O que importa aqui e o par: cuBLAS 12.x + cuDNN 9.x, exigido pelo CTranslate2 4.8.
nvidia-cublas-cu12==12.4.5.8
nvidia-cudnn-cu12==9.1.0.70

# --- captura de audio ---
# comtypes e importado ANTES de sounddevice (com sys.coinit_flags = 0), senao o
# Pa_Initialize() do PortAudio ja chamou CoInitializeEx(APARTMENTTHREADED) e o
# import do comtypes levanta RPC_E_CHANGED_MODE. Ver docs/ARCHITECTURE.md secao 4.
sounddevice==0.5.6
soxr==1.1.0
comtypes==1.4.16

# --- DSP ---
# soxr faz 48k->16k (rejeicao de alias -156 dB contra -73,6 dB do scipy);

# Limites largos de proposito: sao as faixas em que o projeto foi validado, nao
# um pin. numpy<3 existe so para um major novo nao entrar sozinho num setup -Force.
numpy>=1.26,<3
scipy>=1.11

# --- reserva do ARCHITECTURE.md: instalado, ainda nao importado ---
# Nenhum modulo de wispr/ importa os tres hoje (conferido por grep no pacote
# inteiro). Ficam porque sao o caminho ja medido para o proximo passo de cada um:
#   webrtcvad-wheels: VAD proprio em agressividade 2/3 com hangover de 10 frames,
#     caso o vad_filter do faster-whisper se mostre caro (secao 4 do doc);
#   soundfile: leitura/escrita de wav fora do modulo wave da stdlib, que e o que
#     o app.py usa hoje para keep_recordings;
#   pycaw: wrapper de alto nivel sobre o mesmo COM que wispr/audio.py ja fala na
#     mao (IMMDeviceEnumerator, IAudioMeterInformation).
# Consequencia de manter: se um deles nao tiver wheel cp311/win_amd64, o
# `pip install -r` inteiro falha por um pacote que ninguem importa. Se isso
# acontecer no seu setup, comente as tres linhas e siga - nada quebra.

pycaw
